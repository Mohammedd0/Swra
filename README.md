# Bite CRM — سیستەمی بەڕێوەبردنی کلینیکی ددان

وەشانی نمایشی (Demo) بۆ **Bite for Dentistry — هەولێر**.
بێ سێرڤەر کار دەکات: هەموو داتاکان لەناو وێبگەڕدا (localStorage) هەڵدەگیرێن.

## زمان · Language

سیستەمەکە دوو زمانەیە: **ئینگلیزی (بنەڕەت)** و **کوردی**. لە پەڕەی چوونەژوورەوە، لە سەرەوەی پەڕەکان (دوگمەی «کوردی / EN») یان لە مێنیوی لاتەنیشت زمان بگۆڕە.
داتای نموونەیی بە هەمان زمان دروست دەکرێت. ئەگەر داتاکانت گۆڕیبێت، بە زمانی خۆیان دەمێننەوە؛ بۆ داتای نموونەیی بە زمانی تر: بەڕێوەبردن ← باکئەپ و داتا ← دەستپێکردنەوە.

The system is bilingual: **English (default)** and **Kurdish (Sorani, right-to-left)**. Switch from the sign-in page, the top bar or the side menu.

## هەژمارەکانی تاقیکردنەوە

وشەی نهێنی هەموویان: `1234`

| ڕۆڵ | ناوی بەکارهێنەر |
|---|---|
| خاوەن (دەسەڵاتی تەواو) | `owner` |
| دکتۆرەکان | `aras`, `shilan`, `hemn`, `rezhin`, `karwan` |
| سکرتێرەکان (هەر یەکە بۆ یەک دکتۆر) | `shirin`, `rebin`, `lava`, `dlnya`, `ari` |

لە پەڕەی چوونەژوورەوە دەتوانیت تەنها کلیک لە هەر هەژمارێک بکەیت.

## چۆن لەسەر Netlify بڵاوی بکەمەوە (ئاسانترین ڕێگا)

1. بڕۆ بۆ <https://app.netlify.com/drop>
2. فۆڵدەری `bite-crm` (ئەو فۆڵدەرەی `index.html` ی تێدایە) ڕابکێشە و دایبنێ.
3. چەند چرکەیەک دواتر لینکێکت دەداتێ. لە **Site settings → Change site name** ناوەکەی بگۆڕە، بۆ نموونە `bite-crm-demo`.

## چۆن لەسەر GitHub Pages بڵاوی بکەمەوە

1. ڕیپۆیەکی نوێ لە GitHub دروست بکە (بۆ نموونە `bite-crm`).
2. هەموو فایلەکانی ئەم فۆڵدەرە (لەگەڵ `.nojekyll`) بار بکە بۆ ڕیپۆکە (**Add file → Upload files**). فۆڵدەرەکان (`css`، `js`، `js/pages`، `assets`) ڕاکێشە نەک تەنها فایلەکان؛ یان وەشانی «flat» بەکار بهێنە کە هەموو فایلەکان لە یەک شوێندان.
3. **Settings → Pages** → لە **Branch** ـدا `main` و `/ (root)` هەڵبژێرە → **Save**.
4. دوای یەک دوو خولەک لینکەکە دەردەکەوێت: `https://USERNAME.github.io/bite-crm/`

## کارکردن لەسەر کۆمپیوتەر

دوو جار کلیک لە `index.html` بکە. یان بۆ باشترین ئەنجام:

```bash
cd bite-crm
python3 -m http.server 8080
# پاشان بکەرەوە: http://localhost:8080
```

> چارتەکان (Chart.js) و فۆنتەکان لە ئینتەرنێتەوە بار دەبن، بۆیە ئینتەرنێت پێویستە.

## پێکهاتەی پڕۆژە

```
index.html          ← خاڵی دەستپێک
css/styles.css      ← دیزاین (ڕەنگەکانی Bite، تاریک/ڕووناک، مۆبایل، چەپ‌بۆ‌ڕاست و ڕاست‌بۆ‌چەپ)
css/print.css       ← چاپی پسوولە، ڕەچەتە و ڕاپۆرت
js/lang-en.js       ← دەقە ئینگلیزییەکان (English UI text)
js/i18n.js          ← گۆڕینی زمان
js/util.js          ← بەروار، ژمارە، فۆرمات
js/seed.js          ← داتای نموونەیی (٥ دکتۆر، ٥ سکرتێر، ١٧٠ نەخۆش، ~٢٠٠٠ نۆرە)
js/store.js         ← داتا، دەسەڵاتەکان، سنووری بینین بەپێی ڕۆڵ
js/ui.js            ← مۆداڵ، ئاگاداری، فۆرم
js/app.js           ← ڕێگاکان (routing)، مێنیو، گەڕان
js/pages/*.js       ← هەر پەڕەیەک فایلێکی جیا (lists.js = لیستەکانی ئەدمین)
```

ئایکۆنەکان: Phosphor (duotone, MIT). فۆنتەکان: Fraunces + Noto Naskh Arabic (Google Fonts).

## ئەوەی هەیە

- **داشبۆردی جیاواز بۆ هەر ڕۆڵێک**: خاوەن (هەموو کلینیک بە زیندوویی)، دکتۆر (نەخۆشی ئێستا و داهاتوو)، سکرتێر (ڕیزی ئەمڕۆ، بیرخستنەوە، قەرز).
- **نۆرەکان**: خشتەی ڕۆژ/هەفتە/مانگ/لیست، پێکدادانی کات، مۆڵەتی دکتۆر، داواکاری ئۆنلاین، بیرخستنەوە بە واتسئاپ.
- **پەڕگەی نەخۆش**: نەخشەی ٣٢ ددان (FDI)، هەستیاری، پلانی چارەسەر، تێبینی پزیشکی، ڕەچەتە (لەگەڵ ئاگاداری هەستیاری)، وێنەی تیشک.
- **پارە**: پسوولە، قیست، پارەدانی بەش بەش، قەرز بەپێی کۆنی، خەرجی، قازانجی ڕاستەقینە، چاپ.
- **ڕاپۆرت**: بەراوردی دکتۆرەکان، زۆرترین چارەسەر، سەرچاوەی نەخۆش، قەرەباڵغترین کاتەکان، Excel.
- **تاقیگە و کۆگا**: بەدواداچوونی کراون/ڤینیەر، ئاگاداری کەمبوونی کەرەستە.
- **بەڕێوەبردن**: زیادکردن/دەستکاری/ناچالاککردن/سڕینەوەی دکتۆر و سکرتێر، بەستنەوەی سکرتێر بە دکتۆر، خزمەتگوزاری و نرخ، ژوورەکان، خشتەی دەسەڵاتەکان، ڕێکخستن، لۆگۆ، تۆماری «کێ چی کرد»، باکئەپ.
- **لیستەکان و دەرمان** (بەڕێوەبردن ← لیستەکان و دەرمان): ئەدمین دەتوانێت هەموو لیستەکان زیاد بکات، ناویان بگۆڕێت، ڕیزیان بکات، ناچالاکیان بکات یان بیانسڕێتەوە: دەرمانەکان و جۆرەکانیان، ئامۆژگاری ڕەچەتە، هەستیاری، نەخۆشییەکان، سەرچاوەی نەخۆش و نۆرە، نیشانەکان، ناوچەکان، هۆکاری مۆڵەت، پسپۆڕییەکان، پۆلی خزمەتگوزاری، جۆری خەرجی، شێوازی پارەدان، پۆل و یەکەی کۆگا، دابینکەرەکان، جۆری کاری تاقیگە و تاقیگەکان. دەرمان دەتوانرێت بە هەستیارییەکەوە ببەسترێتەوە بۆ ئاگادارکردنەوە لە ڕەچەتەدا.

## تێبینی گرنگ

ئەمە وەشانی نمایشییە. بۆ بەکارهێنانی ڕاستەقینە لە کلینیکدا پێویستە:

- داتابەیس و سێرڤەر (پێشنیار: Supabase/PostgreSQL) بۆ ئەوەی هەموو ١١ کەس هەمان داتا ببینن.
- وشەی نهێنی بە شێوەی شاردراوە (hash) هەڵبگیرێت و سنووری دەسەڵات لە سێرڤەرەوە جێبەجێ بکرێت.
- ناردنی خۆکاری SMS/واتسئاپ لە ڕێگەی WhatsApp Business API.
- باکئەپی ڕۆژانە.
